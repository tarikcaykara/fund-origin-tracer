2. Category tokens

Based on the Okabe–Ito palette, darkened in light and lightened in dark until text reaches 4.5:1. Color is never the only signal: every use shows the lucide icon and the text label. Mixer, sanctioned and scam sit close in hue for protan and deutan viewers, so their icons have distinct shapes (shuffle, ban, skull). Token and other are both neutral and are told apart by icon and label only.

4. Typography

IBM Plex Sans 400/500/600/700 for UI and IBM Plex Mono 400/500/600 for addresses, hashes, amounts and counts. Both are SIL OFL, on Google Fonts and as @fontsource/ibm-plex-sans / @fontsource/ibm-plex-mono for self-hosting (recommended, as the tool is self-hosted and may run offline). System fallbacks: ui-sans-serif, system-ui, Segoe UI / ui-monospace, SF Mono, Menlo, Consolas. Mono uses tabular-nums slashed-zero.

8. Layout and breakpoints

Fluid from 360 to 1440 and up, with no horizontal page scroll at 360. Rules: every grid track is minmax(0,1fr), flex children that hold text get min-w-0, rows wrap, and wide tables turn into stacked lists below md. Horizontal scrolling is allowed only inside the graph canvas.
